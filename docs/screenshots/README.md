# Screenshots de prueba

Capturas de la app YACHAY usadas como evidencia de pruebas en el README.

## Convención de nombres

| Archivo | Qué muestra |
|---|---|
| `01-home.png` | Pantalla inicial (hero + sugerencias) |
| `02-respuesta-con-fuentes.png` | Pregunta real con citas / fuentes |
| `03-fuera-de-dominio.png` | Pregunta fuera de dominio (anti-alucinación) |
| `04-filtro-area.png` | Filtro por área + preguntas frecuentes |

## Cómo regenerarlas

1. Abre la demo: https://yachay-rag-agent-gzjptpjs6mjpqz5454zbrs.streamlit.app/
2. O corre local: `python run_app.py` → http://localhost:8501
3. Captura la pantalla y guarda el PNG en esta carpeta con el nombre de la tabla.
